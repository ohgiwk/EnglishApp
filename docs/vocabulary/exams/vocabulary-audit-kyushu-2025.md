# 九州大学2025年度・公開部分の語彙監査

監査日: 2026-10-02。対象カタログ: 1,400見出し語。

## 対象と限界

[九州大学公式の前期英語問題PDF](https://www.kyushu-u.ac.jp/f/61067/2025_eigo_kyudai.pdf)全20ページから、pypdfで抽出可能なテキストを照合した。大問1〜3の長文本文、大問5の資料は非公開。公開された設問・選択肢・注・出典と、大問4・5の英作文指示などを含む。**難関大学の長文本文を照合できたという意味ではない。**

表紙、受験番号記入例、設問記号、出典URLも集計に含む。画像内で抽出できない文字は含まない。本文・問題の転載はせず、抽出テキストとPDFは作業用の一時ファイルとして扱う。

## 計数方法と結果

既存の `scripts/vocabulary-coverage.mjs` を使用。NFKC正規化、小文字化、番号付きグリフ表記の除去後、英字と内部アポストロフィからなる語を数えた。ハイフンは分割し、原形統合・固有名詞除外・語義照合はしない。

| 指標                   |          結果 |
| ---------------------- | ------------: |
| 抽出表記の延べ数       |           809 |
| 抽出表記の異なり数     |           382 |
| 見出し語との延べ一致   | 399（49.32%） |
| 見出し語との異なり一致 | 152（39.79%） |

数字は抽出結果の機械的な表記一致率であり、理解率・合格可能性・試験全体の語彙網羅率ではない。共通テストの集計とは対象範囲が違うため、難易度比較にも使わない。入力テキストとカタログのハッシュ、頻度上位の不一致表記は[集計JSON](vocabulary-coverage-kyushu-2025.json)に保存した。

PDF第10ページ（冊子7ページ、大問2の問3・4）を画像と照合したところ、flexibilityが抽出時に分断されていた。数値の再現性を保つため今回は未補正とし、候補語の判定では画像の綴りを用いた。全ページの抽出精度は未検証。
