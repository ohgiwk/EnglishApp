# 会津大学2024年度 英語・第4問 第2対話の語彙照合

## 対象と確認状態

- 公式資料: [2024年度入学試験問題（数学・英語）](https://u-aizu.ac.jp/files/page/others/General2024.pdf)。PDF全44ページのうち、第9ページに2024年度英語の表紙がある。
- 今回の対象: 第31ページの、学生のChatGPT利用を扱う対話本文。13の発言すべてを対象とし、最後の空欄だけの発言は数えない。
- 除外: 話者名、下線の参照記号、空欄番号、第30ページのグラフ、指示文、設問、選択肢。発言内の呼び掛けの人名は残す。第4問全体や試験全体の網羅率ではない。
- PDF画像を目視して転記し、gpt-6-lunaを指定した別エージェントも画像と転記を照合。欠落・追加・誤記の指摘なし。実行結果からのモデル識別情報は取得できない。
- 本文の内容は試験中の対話であり、AIの性能・健康効果などの事実を検証したものではない。

## 数え方と再現条件

各発言の行折り返しをつなぎ、発言間は改行する。話者ラベルと注記を除き、アポストロフィをASCIIへ統一、ダッシュはem dash、末尾に改行1個を置いた。PDFはスキャン画像で、pypdfでは対象ページの文字を抽出できなかったため手動転記を用いた。

`scripts/vocabulary-coverage.mjs` に本文・年度・問題名・公式URL・抽出範囲を渡して集計した。NFKC、小文字化、内部アポストロフィを含む英字単位で数え、ハイフンは分割する。数字は数えず、原形統合・固有名詞除外は行わない。AIなどの略語もそのまま数える。

[集計JSON](vocabulary-coverage-aizu-2024-dialogue2.json) にPDF・本文・ID/見出し語一覧のSHA-256、対象ページ、頻度と分類を保存した。再現時は同じPDFの第31ページを同じ条件で転記し、本文ハッシュを確認する。2回の集計結果が一致し、語彙JSONが不変であることも確認した。対話本文の転載や教材への取り込みは行わない。

## 不足と次の編集候補

- 基本見出し語の未収録: `graph`（2回）、`really`（2回）、`absolutely`、`careful`、`seven`、`yes`、`hey`（各1回）。グラフ読解、程度・応答、基本形容詞・数詞に穴がある。特にgraph・really・carefulを優先して検討する。
- 活用形の未一致にも原形の不足がある。`tasks`→task、`jobs`→job、`lost`→loseは、原形自体も未収録。単なる表記差として除外せず、一般的な仕事・行動の基本語として追加を検討する。
- `boring`の対応候補boreも未収録。形容詞としての独立した学習価値と、動詞・語族の扱いを次の編集で判断する。活用形を一律に別見出しへ追加しない。
- `according`はaccording toという連語で現れる。単語数と熟語数を分け、連語や用法として扱う。
- 代名詞・短縮形、AI関連の略語・人名を一致率だけのために追加しない。既存の原形がある語とない語を分けて判断する。

今回は不足の確認までとし、語彙追加はしていない。既存の慶應2025に加え、別大学・別年度の本文照合が1件増えた。ただし短い対話1題であり、難関大学の長い論説文全般への対応を証明しない。今後は5,000語到達時の残要件確認と、基本語の穴埋め・別題材の本文照合を各1件ずつ進める。
