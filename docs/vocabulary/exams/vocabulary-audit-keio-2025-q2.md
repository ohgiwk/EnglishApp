# 慶應義塾大学2025年度理工学部・英語第2問の語彙監査

監査日: 2026-10-02。対象カタログ: 2,500見出し語。

## 対象と抽出

[大学公式の2025年度問題一覧](https://www.keio.ac.jp/ja/admissions/faculty/examinations/general-admissions/question-2025/)の理工学部「外国語」から[公式PDF](https://www.keio.ac.jp/files/dd6e35cf8b2472fac48bfc4308637c20bb503dd7c616cc3e04f2a8d6cc2aa2b7)を確認した。第2問の本文はPDF第4ページ、設問は第5ページ。今回は**本文7段落のみ**を計数する。設問ページは範囲確認のため閲覧したが、選択肢・設問の英文は計数しない。

題材は持久的な運動と心臓の健康に関する研究。PDFに記載された出典はJennifer Couzin-FrankelのScience掲載記事（2024）で、試験向けに編集されている。原著との同一性や、記事中の医療情報の現在の妥当性は検証対象ではない。

画像PDFの本文を手動転記し、2種類の解像度で描画した第4ページと照合した。拡大確認でracingの転記を修正した。独立した二重転記は未実施。日本語の指示、下線番号、語注、出典行、ページ番号は除外し、行末の折り返しを結合した。本文中の固有名詞・略語・引用内の英文・語注付き単語は残す。本文とページ画像は作業用一時ファイルにのみ保存し、リポジトリには転載しない。

## 集計

既存の `scripts/vocabulary-coverage.mjs` に上記の抽出範囲を渡した。NFKC、小文字化、アポストロフィを含む英字単位への分割を行い、ハイフンは分割する。数字は計数しない。原形統合・固有名詞除外は行わない。

結果は[集計JSON](vocabulary-coverage-keio-2025-q2.json)に保存した。公式PDF・入力テキスト・カタログのSHA-256を含む。再現時はPDF第4ページを同じ範囲で転記し、ハッシュの差が出た場合は句読点や改行も含めて確認する。

表記一致は理解率でも、原形単位の網羅率でもない。略語AF、人名、活用形などが未一致となる。第1問は2,000語時点、第2問は2,500語時点であり、題材・語数も違うため、両者の率の差を学習効果として比較しない。第1問の監査JSONは当時の記録として保持した。

## 活用形と別義

13種類、延べ33箇所について既存の見出し語に対応する活用形・複数形を手動確認した。対応表とIDはJSONに記録した。この33箇所を上の一致数に足して原形網羅率を作ることはしない。未一致表記すべてを検証した結果ではないためである。

- patientの「患者」、studyの「研究」、documentの「記録する」は、既存データの別義で扱えることを確認した。
- raceの動詞用法は不足している。本文の心臓の速い鼓動を表す用法は、現状の名詞「競走・人種」だけでは説明できない。IDを保ったまま別義を補う候補とする。
- trainingのような名詞用法や句表現は、語形だけを機械的にtrainへまとめて確認済みとはしない。
