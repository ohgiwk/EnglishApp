## 編集基準と参照元

`editorial-policy-v1` は、この節の編集方針を指す。基本義の学習段階、読解上の重要性、抽象度、題材のバランスからレベルを判断する。Web頻度は補助情報とし、CEFR・英検級・学年への厳密な対応は主張しない。`reviewed` は本リリースで個別に編集した記録であり、専門家の外部認証や入試頻度の実測を意味しない。

`legacy-frequency-order` は初期版のWeb頻度順による選定・均等分割を指す。この参照のみで確認済みにはしない。

規模・対象範囲の参考資料（個々の語のレベルの出典ではない）:

- [文部科学省・中学校学習指導要領解説 外国語編](https://www.mext.go.jp/content/20210531-mxt_kyoiku01-100002608_010.pdf)、本文33〜34ページ。
- [旺文社・英単語ターゲット1900](https://www.obunsha.co.jp/product/detail/034646)。対象範囲のみ参考とし、訳・例文・配列を転用しない。

活用形だけで見出し語数を増やさず、派生語は独立した学習価値があれば別見出しにする。熟語コースは別途設計し単語数に含めない。多義語のレベルは基本義で決め、重要な別義は `additionalMeanings` に品詞・和訳・英和例文を記録する。別義は表示用であり、四択問題は従来どおり基本義を使う。

## 編集と公開の手順

単語の編集元は `src/data/vocabulary/v0001-v0100.json` などの100語単位のJSON。意味・例文・和訳・別義・確認状態を同じレコードで管理する。[ファイル一覧と編集方法](../../../src/data/vocabulary/README.md) を参照。`vocabulary-catalog.ts` は自動読み込み専用で、単語そのものは記述しない。旧 `generate-vocabulary.mjs` は廃止した。並び順からID・レベルを再生成しない。

1. 既存語はIDと大文字小文字を正規化した見出し語の対応を保持する。月名などの誤った大小文字表記はIDを維持して修正できる。新規語は未使用のIDを明示的に付ける。既存の `v0001`〜`v1000` は固定、追加済み1,650語は `v1001`〜`v2650`。
2. `level` と `editorial.recommendedLevel`、判定理由 `reason`、参照元 `references`、確認状態 `reviewStatus` を編集する。候補は基礎語の欠落、高校・標準入試語、難関語の順に評価する。
3. 語義・品詞・英文・和訳を照合し、確認した独自例文に `exampleInfo.source: authored` を付ける。未確認の生成例文は穴埋め・並べ替えに出さない。既存の手書き例文は単語のレベル変更後も利用できる。
4. `npm run vocabulary:check` で重複・編集情報・語義と例文の必須項目を確認する。文法や難易度の適切さはこの検証では保証されない。
5. `npm run check` と `npm run build` を通し、50語単位で追加する。レベル別実数と昇格条件は現データから算出する。取得済みの試験資格・合格、単語IDに紐づく学習履歴は維持する。

全件監査は完了した。次段階は、未収録の基礎語と高校・入試読解語を候補単位で評価して追加する。既存の意味を大幅に変更する場合は、学習履歴との意味の連続性も確認する。目標との差分2,350語を無審査でまとめて生成しない。

## 公開問題との初回照合

2025年度共通テスト本試験・英語リーディングの[公式公開PDF](https://www.dnc.ac.jp/albums/abm.php?d=771&f=abm00005957.pdf&n=2025_op_20_reading.pdf)全32ページを対象とした。公開版に含まれない文章や抽出できない画像内文字は対象外。本文だけでなく設問・選択肢・抽出可能な図中文字も含めた。

抽出した英字列を小文字化し、アポストロフィを含む語を一単位として見出し語と完全一致比較した。ハイフンは分割し、数値ラベルは数えない。pypdfの未対応字形 `/cNNN` は除去する。原形への統合、固有名詞の除外、語義の一致判定は行っていない。

初回1,050語の結果は `vocabulary-coverage-2025-1050.json` に保存した。最新の2,650語での再照合結果は `vocabulary-coverage-2025.json` に保存している。同じ5,571出現語・1,615異なり語のうち、現在の表記一致は3,618出現語・662異なり語（64.94%・40.99%）。初回は3,258出現語・484異なり語（58.48%・29.97%）だった。**この数値は原形ベースの語彙カバー率や理解率ではない。** be の活用形なども未一致になるほか、PDF抽出の断片も含まれる。難関大への対応を判定する材料としては不十分である。

上位の未一致語を確認すると、活用形を追加すべきという結論にはならない一方、睡眠や移動、発表・説明など、基礎的な題材にも未収録語が残る。次回は代名詞・所有表現と日常の動作・状態を優先し、原形・語義を確認して採否を決める。難関大については別途、公開されている二次・私大入試問題の複数年度を同じ方法で照合する。

再現手順（公開PDFや全文抽出テキストはリポジトリに収録しない）:

```sh
python3 -c 'from pypdf import PdfReader; import sys; print("\n".join(p.extract_text() for p in PdfReader(sys.argv[1]).pages), end="")' reading.pdf > reading.txt
node scripts/vocabulary-coverage.mjs reading.txt 2025 '共通テスト本試験・英語リーディング・公開PDF全32ページ' 'https://www.dnc.ac.jp/albums/abm.php?d=771&f=abm00005957.pdf&n=2025_op_20_reading.pdf'
```

レポートには入力テキスト・見出し語一覧のSHA-256も記録する。抽出環境による差異や、語彙追加後の比較対象の変化を判別できる。
